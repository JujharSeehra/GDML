Hi Everyone!
This is GDML, a machine learning program that is able to play the hit game Geometry Dash.
How it works is it creates a machine learning model from user generated training runs on a level, then builds a model, and then continuosly improves the model by exploring new options every run, until it beats the level.
Right now, GDML is trained towards the default level Base after Base, but feel free to use this artitecture for other levels! 
Just 
a. Change the cv2 window settings to match your computer
b. reset all recordings
c. use recorder.py 5 times to create 5 different training sessions (The longer, the better!)
d. Use train_strong.py to train a model
e. Rename the model to match online_agent.py
f. Run online_agent.py, and watch the machine continously improve!


The shipped release will contain a .dmg file, which you can use to easily access this project!
Good luck, and I hope you find this robot enjoyable to play around with!
